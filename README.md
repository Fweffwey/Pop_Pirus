# Pop_Pirus
Pop_os Icons + Papirus icons = Pop_Pirus. I wanted to make the Pop!_OS feel like the Pop!_os we've for all these years. 

One thing to make VERY clear, is that I do now OWN these icons nor am I the creator of them. I combined these icons from the team at[System76](https://github.com/system76), [PapirusDevTeam](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme) and [mjkim0727
](https://github.com/mjkim0727/Pop-Extended). I don't expect to get much out of this thing. This was just honestly for me because of my need to fix some pixelated stock icons and also just to make my system match cosmetically. I have also included some Wallpapers that I did create/tweak spesifically for Pop!_OS.
